# Campaign Threat Radar (v1.8)

> **Minecraft Java 1.21.10 без модлоадера:** datapack с ванильными командами находится в [`minecraft-vanilla/`](minecraft-vanilla/README.md). Шуточный клиентский ресурс-пак для Minecraft с анимированной текстурой из видео (и его звуком) на всех стандартных блоках — в [`minecraft-xray-resourcepack/`](minecraft-xray-resourcepack/README.md). Исходный Mindustry-проект не меняется.

Клиентский тактический HUD-мод для **Mindustry v8** (билды 154+).

Располагается в **верхнем правом углу (левее миникарты)** и отвечает на два
вопроса: **что сейчас угрожает базе**, **что улучшить** и **как компактно
защитить выбранный участок** — коротким планом с проверкой свободного места.

Мод помечен как `hidden: true` — он является **чисто клиентским**, не создает сущностей, не меняет правила мира, не шлёт сетевых пакетов и **не влияет на сервер** (вы можете свободно заходить на любые многопользовательские сервера и играть в кампанию). Единственное исключение — **явно включённый автопилот**: он работает только в локальной одиночной кампании и действует только вашим юнитом, как обычный игрок.

## 🎯 Что показывает панель

Панель показывает только то, на что стоит реагировать: состояние волны, текущую
угрозу и конкретные места для усиления. Карта стала крупнее: до **220 UI units**
(раньше 160), а подписи ограничены по ширине и переносятся. На небольших окнах
размер карты и ширина панели автоматически уменьшаются — панель занимает около
40% ширины экрана или меньше; неважные счётчики базы и сессии скрыты.

```text
РАДАР · Волна 8/30 · следующая через 1:15
Враги: 12 (земля 10, авиация 2)
Сила: HP ~2.4k · урон 132/с · ближайший 50 тайлов
⚠️ К ядру идут 2 · прибытие 8–13 с · ядро может пасть через ~18 с
🎯 Что улучшить: 1) ПВО · СЗ 124,86 — нет защиты от авиации
2) ТУРЕЛЬ · В 210,75 — нужно +68 урона/с · ещё 1 место ✚ на карте
🏰 Оборона выдержит ~6 волн · риск на ~15-й: авиация
Следующая волна 9: 17 врагов · 10×Dagger, 4×Mace
⚠ ⚡ Энергия: не хватает 40/с · батарея 70% (~2:10)
```

### Разбор по строкам

| Строка | Смысл |
|---|---|
| `РАДАР · Волна` | номер волны, идёт ли бой и время до следующей волны |
| `Враги` | сколько врагов на карте, отдельно земля/авиация и боссы |
| `Сила` | суммарное здоровье и урон врагов, расстояние до ближайшего |
| `⚠️ К ядру идут` | сколько врагов приближается и примерное время до ядра |
| `🎯 Что улучшить` | **главное:** что построить или починить и в каком секторе; показаны два самых важных пункта, остальные отмечены ✚ на карте |
| `🏰` | сколько волн выдержит оборона и какая угроза её пробьёт |
| `Следующая волна` | ближайший состав врагов, чтобы подготовиться |
| `⚠` | проблемы с ядром, энергией, патронами или повреждёнными постройками |

Под картой легенда подписывает основные значки: ядро, игрок, точка спавна,
наземные/воздушные враги, босс и места для усиления.

## 🧭 «УЛУЧШИТЬ» — где именно улучшать

Это самый важный блок панели. Для каждого ядра мод смотрит **реальные подходы
врагов** (точки спавна волн) и оценивает точку на кольце обороны в 26 тайлов
от ядра. Проверяется, какие турели **действительно достают** до этой точки
(с учётом их радиуса и того, бьют ли они по земле или по воздуху) и сколько
HP стен стоит перед ними.

Сектор попадает в список, если:

| Действие | Когда |
|---|---|
| 🛡 **ПВО** | в секторе нет (или мало) турелей, бьющих по воздуху |
| 🚜 **ТУРЕЛЬ** | мало урона по земле — показывается, сколько не хватает DPS |
| 🧱 **СТЕНЫ** | перед турелями почти нет стен — показывается, сколько HP достроить |
| 📦 **ПАТРОНЫ** | рядом стоит турель без боеприпасов (метка на самой турели) |
| 🔧 **РЕМОНТ** | постройка обороны сильно повреждена (метка на её месте) |

Каждый пункт содержит:

* **номер** в списке — пункты отсортированы по критичности (красный номер = срочно);
* **что делать** — ПВО, ТУРЕЛЬ, СТЕНЫ, ПАТРОНЫ или РЕМОНТ;
* **где** — направление от ядра (С/СВ/В/…) и координаты тайла, например `СЗ 124,86`;
* **сколько** — недостающий DPS, недостающие HP стен или процент HP постройки.

Цвет пункта совпадает с цветом метки ✚ на тактической карте, поэтому пункт
списка легко находится глазами на карте. Критичные места на карте обведены
дополнительным красным кольцом.

## 🛡 Планировщик защиты участка

1. Нажмите на нужную точку на тактической карте; повторный клик по ней снимает
   выбор. Мод показывает выбранные координаты и поворачивает схему к ближайшему
   реальному спавну волн (если спавнов нет — к ближайшему врагу).
2. Компактный базовый шаблон: **7 медных стен, 4 Duo, 2 Scatter и 1 Mender**.
   Цветные значки на карте показывают каждый рекомендуемый тайл.
3. Проверяются реальные тайлы мира: край карты, жидкая поверхность и уже занятые
   блоками клетки. Если точка шаблона занята, планировщик пробует сдвинуть её не
   более чем на 2 тайла; иначе показывает, сколько мест не поместилось.
4. Сам план — **только рекомендация**: клик по карте ничего не строит и мир не
   меняет, поэтому радар работает как клиентский HUD и на серверах. Блоки
   ставит только явно включённый автопилот (см. ниже) в одиночной кампании.

## 🤖 Автопилот Serpulo (этап 1: один сектор)

Под текстом радара есть строка состояния и три кнопки: **▶ Автопилот**,
**⏸ Пауза**, **■ Стоп**. По умолчанию автопилот **выключен** и ничего не меняет.

**Где работает:** только локальная одиночная кампания **Serpulo** на сложности
**Normal**. В сетевой игре, вне кампании, на другой планете или сложности запуск
невозможен, а если условие нарушится во время работы — автопилот сразу
останавливается и пишет причину.

**Что делает** (одно небольшое действие в секунду, каждое перепроверяется):

| Приоритет | Действие | Как именно |
|---|---|---|
| 1 | 📦 Патроны | берёт патроны из ядра своим юнитом и относит в турель, где их меньше трети |
| 2 | 🛡 Оборона | на самом слабом подходе из «Что улучшить» ставит Duo → стены → Scatter (что открыто и по карману) |
| 3 | 🔧 Восстановление | восстанавливает разрушенные постройки из очереди команды |
| 4 | ⛏ Экономика | ставит механический/пневматический бур на руду и прокладывает конвейер до ядра (до 12 буров) |
| 5 | 🌊 Волна | вызывает следующую волну, только если нет врагов, ядро цело и прогноз радара считает её безопасной |
| 6 | ⛏ Добыча | юнит ядра сам добывает медь/свинец рядом с ядром |

Всё делается обычными игровыми механиками: очередь строительства своего юнита,
добыча, передача предметов и кнопка «следующая волна». Сохранения и прогресс
сектора не подменяются. 40 меди всегда остаются в резерве для патронов.

**Безопасность:**

* **⏸ Пауза** — сразу останавливает движение и новые действия; **■ Стоп** — ещё и
  отменяет постройки, которые поставил автопилот.
* Строительство стоит 45 с (нет ресурсов/места) или одно и то же действие
  проваливается 5 раз подряд → состояние **НУЖНА ПОМОЩЬ** с причиной.
* Загрузка мира или сохранения всегда выключает автопилот — включите его снова,
  когда проверите сектор.
* Сектор захвачен → **СЕКТОР ЗАХВАЧЕН**; следующий сектор пока выбирает игрок.

**Чего пока нет (следующие этапы):** атака вражеских баз, исследования, выбор
секторов на карте планеты, энергия, кремний/графит и сложные производственные цепочки.
Сектор с атакой базы или без волны победы автопилот честно отказывается проходить.
Подробнее — [`AUTOPILOT_ROADMAP.md`](AUTOPILOT_ROADMAP.md).

> ⚠️ Логика покрыта тестами (Node и Java), но в настоящей Mindustry этот этап ещё
> не прогонялся. Первый запуск лучше делать на Ground Zero и держать палец на ⏸.

## 🗺 Остальные возможности

1. **Тактическая карта всей игровой области:**
   - Показывается **вся карта целиком** с сохранением пропорций (letterbox, без растяжения): далёкие ядра, спавны и враги не пропадают.
   - 🔵 Синие квадраты — ваши ядра (слабейшее обведено кольцом), ⚪ белая точка — вы, 🟥 пустые красные квадраты — точки спавна волн.
   - 🔴 Красные точки — наземные враги, 🟠 оранжевые — авиация, 🔴 с кольцом — боссы. Враги за границей карты прижимаются к краю.
   - ✚ Жёлтые/оранжевые метки — места, которые нужно улучшить (цвет = тип улучшения).
   - После клика по карте выбранный участок обводится; цветные значки — проверенный по местности шаблон компактной защиты.
   - Пунктирная линия соединяет ближайшую угрозу именно с тем ядром, к которому она идёт.

2. **Реалистичные предсказания:**
   - ⏱ ETA считается по **реальной скорости типа юнита**, а не по текущей мгновенной: диапазон «12–18 с» вместо бессмысленного «500 с».
   - 📐 Учитываются обход препятствий (+30 % пути), разгон, потери времени на разворот и добивание текущей цели.
   - 🛡 Реальный DPS обороны (`estimateDps()`) сравнивается с DPS врага.

3. **Прогноз по волнам:**
   - 🏰 Мод берёт настоящее расписание волн (`rules.spawns` — то, чем игра реально спавнит врагов, с учётом сложности кампании и щитов) и проигрывает до 100 следующих волн против вашей обороны: HP и урон каждой волны, урон турелей по земле и по воздуху, HP линии обороны, её износ и починка между волнами. Итог: `🏰 Оборона выдержит ~6 волн · риск на ~15-й: авиация` или `🏰 Оборона выдержит до победы (волна 30) ✅`.
   - 🌊 Следующая волна заранее: номер и состав (или суммарное HP, если состав недоступен).
   - 💀 Предупреждение о боссе/гардиане за несколько волн до его прихода.

4. **Диагностика базы:**
   - 🚨 Состояние ядра (процент HP), ⚡ дефицит энергии и блэкаут, 📦 турели без патронов, 🛠️ повреждённые постройки, ✅ «Всё спокойно», когда всё в порядке.
   - Точные метки патронов и ремонта не дублируются: если они уже отмечены в списке или на карте, отдельное предупреждение не выводится.

## 📦 Сборки

Есть две равноценные по логике версии (ставьте и включайте **только одну**):

| Файл | Что это | Как работает |
|---|---|---|
| `CampaignThreatRadar.jar` | Java-мод (Java 17) | Рекомендуемая основная сборка |
| `CampaignThreatRadar.zip` | Скриптовый мод (Rhino JS API) | Скриптовый архив (`Campaign Threat Radar (ZIP)`), Java не требуется |

## 🚀 Установка

### Вариант 1: Через меню игры (самый простой, для jar)
1. В игре перейдите в **Моды** → **Импорт** → **Импорт из GitHub**.
2. Введите репозиторий: `homa95120-wq/-` (название репозитория — это буквально дефис).
3. Игра автоматически скачает актуальный `.jar` из последнего релиза.

### Вариант 2: Вручную через архив
1. Скачайте файл `CampaignThreatRadar.jar` из Releases или `dist/CampaignThreatRadar.zip` из репозитория.
2. Положите файл (целиком архив, **НЕ распаковывая!**) в папку `mods`:
   - **Steam (любая ОС):** `<папка игры>\saves\mods\` (например `...steamapps\common\Mindustry\saves\mods\`)
   - **Windows:** `%APPDATA%\Mindustry\mods\`
   - **Linux:** `~/.local/share/Mindustry/mods/`
   - **macOS:** `~/Library/Application Support/Mindustry/mods/`
3. Перезапустите Mindustry, убедитесь, что мод включен в списке модов, и запустите игру/кампанию.

## 🛠️ Сборка и тестирование

```bash
# Тесты чистой логики (Node.js)
node scriptmod/test-logic.js

# Тесты HUD-интерфейса и автопилота на макете мира (Node.js)
node scriptmod/test-hud.js

# Тесты логики автопилота на Java (нужен JDK 17, игра не нужна)
javac -d build/autopilot-check src/main/java/campaignradar/AutopilotLogic.java src/test/java/campaignradar/AutopilotLogicCheck.java
java -cp build/autopilot-check campaignradar.AutopilotLogicCheck

# Сборка ZIP-версии мода
python3 scriptmod/build.py

# Сборка Java JAR-версии (требуется JDK 17)
./gradlew jar
```

> Прогноз по волнам, метки усиления и планировщик — эвристики, а не гарантия. Планировщик проверяет границы карты, воду и занятые блоки, но не проверяет технологический уровень, стоимость ресурсов, маршрут строительства, рельефные линии огня или серверные правила. Сама схема лишь подсказывает место и состав; блоки ставит только явно включённый автопилот.

# Быстрый старт: Автономное движение робота

Пошаговая инструкция по запуску автономного движения.

## Шаг 1: Подготовка железа

### Подключите оборудование:

1. **Две камеры Logitech Brio 500**:
   - Подключите к USB 3.0 портам
   - Левая камера → `/dev/video0`
   - Правая камера → `/dev/video1`

2. **Лидар RPLIDAR** (или совместимый):
   - Подключите к USB порту
   - Настройте в `.env` файле

3. **Модули колёс Arduino**:
   - 4 модуля через USB (FL, FR, RL, RR)
   - Настройте порты в веб-интерфейсе

### Проверьте подключение:

```bash
# Проверка камер
ls -l /dev/video*
# Должно быть: video0, video1, video2, video3 (и другие)

# Проверка USB устройств
lsusb | grep -i camera
lsusb | grep -i lidar

# Проверка портов колёс
ls -l /dev/ttyUSB* /dev/ttyACM*
```

## Шаг 3: Настройка конфигурации

Отредактируйте `.env` файл:

```bash
cp .env.example .env
nano .env
```

Добавьте настройки автономного движения:

```bash
# ==========================================
# АВТОНОМНОЕ ДВИЖЕНИЕ
# ==========================================

# Включить автономное движение
RC_AUTO_NAV_ENABLE=1

# Параметры дороги
RC_ROAD_WIDTH_M=7.5          # Ширина дороги (метры)
RC_SAFE_DISTANCE_M=0.8       # Безопасное расстояние от края

# Параметры движения
RC_AUTO_NAV_SPEED_MPS=0.08   # Скорость исследования (м/с)
RC_SCAN_INTERVAL_S=0.5       # Интервал сканирования (секунды)
RC_TURN_ANGLE_DEG=30.0       # Угол поворота при препятствии

# Настройки камер (если порты отличаются)
RC_CAMERA_FRONT=/dev/video0   # Левая камера
RC_CAMERA_REAR=/dev/video1    # Правая камера

# ==========================================
# СУЩЕСТВУЮЩИЕ НАСТРОЙКИ (не удаляйте)
# ==========================================

# Лидар
RC_LIDAR_SOURCE=ros2         # Используем ROS2 для лидара
RC_LIDAR_PORT=/dev/ttyUSB0   # Порт лидара (настройте)

# Колёса (настройте в веб-интерфейсе)
RC_WHEEL_FL_PORT=/dev/ttyACM0
RC_WHEEL_FR_PORT=/dev/ttyACM1
RC_WHEEL_RL_PORT=/dev/ttyACM2
RC_WHEEL_RR_PORT=/dev/ttyACM3

# Калибровка скорости (ВАЖНО!)
RC_NAV_MPS_PER_PERCENT=0.01  # Измерьте на роботе
RC_NAV_SPEED_MPS=0.05
RC_NAV_MAX_PERCENT=4
```

## Шаг 6: Калибровка колёс

**ВАЖНО**: Перед первым движением откалибруйте колёса!

1. Откройте веб-интерфейс: `http://<IP-робота>:8080`
2. Войдите как оператор
3. Перейдите в **«Руление и тяга»**
4. Нажмите **«Калибровать все колёса»**
5. Дождитесь завершения калибровки

## Шаг 7: Первый тестовый запуск

### Подготовка:

1. **Вывесите колёса** (поднимите робота на подставках)
2. **Проверьте E-STOP** (должен быть доступен)
3. **Освободите пространство** вокруг робота
4. **Проверьте освещение** для камер

### Тест объединения камер:

1. Откройте: `http://<IP-робота>:8080/autonomous`
2. Внизу страницы должно быть **«Вид с камер»**
3. Проверьте, что изображение отображается и обновляется
4. Видны ли оба обзора (левый и правый)?

### Тест автономного движения (с вывешенными колёсами):

1. На странице автономного движения проверьте статус
2. Должно быть: **Enabled: true**, **Active: false**
3. Нажмите **«▶ Запустить»**
4. Наблюдайте за колёсами — они должны:
   - Сначала выставиться прямо (0°)
   - Начать медленно вращаться
5. Проверьте показатели:
   - **Пройдено**: должно расти
   - **Время**: считает секунды
   - **Препятствий**: может быть 0 (колёса вывешены)
6. Нажмите **«⏹ Остановить»**
7. Колёса должны остановиться

Если всё работает — можно опускать робота на землю!

## Шаг 8: Автономное движение на земле

### Первый запуск на земле:

1. **Подготовьте площадку**:
   - Ровная поверхность
   - Ширина минимум 3 метра
   - Нет людей и препятствий
   - Хорошее освещение

2. **Проверьте безопасность**:
   - E-STOP готов к нажатию
   - Оператор наблюдает за роботом
   - Путь отхода свободен

3. **Запустите автономное движение**:
   ```bash
   # Через веб-интерфейс
   http://<IP-робота>:8080/autonomous
   # Нажмите «▶ Запустить»
   ```

4. **Наблюдайте**:
   - Робот выставит колёса прямо
   - Начнёт медленно двигаться вперёд
   - Будет держаться в центре дороги
   - При препятствии — остановится и объедет

5. **Контролируйте**:
   - Следите за статусом на экране
   - При любой проблеме — E-STOP
   - Расстояние до краёв > 0.8 м

## Шаг 9: Построение карты

Карта строится автоматически во время движения:

1. Откройте **«Карта лидара»**: `http://<IP-робота>:8080/console`
2. Наблюдайте построение карты в реальном времени:
   - **Зелёные точки** — свободное пространство
   - **Красные точки** — препятствия
   - **Серые точки** — неизученные области
3. Чем дольше робот движется, тем полнее карта

### Экспорт карты:

```bash
# Через API
curl http://<IP-робота>:8090/api/slam/map > map.json

# Просмотр карты в RViz (если установлен ROS2)
rviz2
```

## Частые проблемы и решения

### Проблема: "Камеры недоступны"

**Решение:**
```bash
# Проверка камер
ls -l /dev/video*

# Права доступа
sudo usermod -aG video $USER
# Выйдите и войдите снова

# Проверка OpenCV
python3 -c "import cv2; print(cv2.__version__)"
```

### Проблема: "Лидар не готов"

**Решение:**
```bash
# Проверка ROS2
source /opt/ros/humble/setup.bash  # Или ваша версия
ros2 topic list

# Проверка драйвера лидара
./scripts/ros2_lidar.sh --status

# Порт лидара
ls -l /dev/ttyUSB*
# Обновите RC_LIDAR_PORT в .env
```

### Проблема: "Колёса не двигаются"

**Решение:**
```bash
# Проверка портов
./scripts/master_check.py --list

# Проверка отдельного колеса
./scripts/master_check.py --port /dev/ttyACM0

# Калибровка колёс
# Через веб-интерфейс: «Руление и тяга» → «Калибровать все колёса»
```

### Проблема: "Автономное движение не запускается"

**Проверьте:**
1. `RC_AUTO_NAV_ENABLE=1` в `.env`
2. Калибровка скорости: `RC_NAV_MPS_PER_PERCENT` установлен
3. E-STOP снят
4. Лидар работает
5. Колёса откалиброваны

### Проблема: "Изображение с камер не отображается"

**Решение:**
```bash
# Проверка сервиса
curl http://localhost:8080/api/dual-camera/status

# Тест камер
python3 scripts/test_autonomous.py --test-cameras

# Перезапуск
./scripts/stop.sh
./scripts/start_robot.sh
```

## API для интеграции

### Python пример:

```python
import requests

# Базовый URL
BASE_URL = "http://192.168.1.100:8080"

# Запуск автономного движения
response = requests.post(f"{BASE_URL}/api/autonomous/start")
if response.ok:
    print("Автономное движение запущено")

# Получение статуса
response = requests.get(f"{BASE_URL}/api/autonomous/status")
status = response.json()
print(f"Фаза: {status['phase']}")
print(f"Пройдено: {status['distance_traveled']} м")

# Остановка
response = requests.post(
    f"{BASE_URL}/api/autonomous/stop",
    json={"reason": "Тестовая остановка"}
)
```

### JavaScript пример:

```javascript
// Запуск автономного движения
async function startAutonomous() {
    const response = await fetch('/api/autonomous/start', {
        method: 'POST'
    });
    const data = await response.json();
    console.log('Статус:', data);
}

// Получение статуса
async function getStatus() {
    const response = await fetch('/api/autonomous/status');
    const data = await response.json();
    console.log('Пройдено:', data.distance_traveled, 'м');
    console.log('Время:', data.exploration_time, 'с');
}

// Остановка
async function stopAutonomous() {
    const response = await fetch('/api/autonomous/stop', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ reason: 'Остановка из JS' })
    });
}
```

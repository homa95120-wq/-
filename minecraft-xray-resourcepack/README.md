# Anime Girl Blocks — Minecraft Java 1.21.10

Resource pack для Java 1.21.10: заменяет все стандартные блоки и их иконки в инвентаре одной пиксельной текстурой с аниме-девочкой — включая руды, сундуки, воду и лаву. Блоки сохраняют игровые свойства, но формы многих блоков выглядят как кубы. Текстуры мобов, игроков и предметов, которые не являются блоками, остаются стандартными. Это шуточный визуальный пак, не ESP и не чит.

## Установка

1. Скачай `dist/AnimeGirlBlocks-1.21.10.zip` и **не распаковывай**.
2. В Minecraft открой **Настройки → Наборы ресурсов → Открыть папку наборов ресурсов**.
3. Перемести ZIP в эту папку, вернись в игру и включи **Anime Girl Blocks**.
4. Отключи пак в том же меню, чтобы вернуть обычные текстуры.

## Сборка и проверка

```sh
python3 build.py
```

Скрипт создаёт `dist/AnimeGirlBlocks-1.21.10.zip` и проверяет структуру архива и JSON-файлы. Текстура лежит в `assets/anime_girl.png`.

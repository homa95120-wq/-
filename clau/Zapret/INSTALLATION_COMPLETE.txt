🚀 СЛЕДУЮЩИЕ ШАГИ:

  1. Установите зависимости:
     $ pip install opencv-python numpy

  2. Добавьте настройки в .env:
     $ cat .env.autonomous.example >> .env
     $ nano .env

  3. Протестируйте систему:
     $ python3 scripts/test_autonomous.py --test-full

  4. Интегрируйте в приложение (см. autonomous_integration_example.py)

  5. Изучите документацию:
     - Быстрый старт: docs/QUICKSTART_AUTONOMOUS.md
     - Полная документация: docs/AUTONOMOUS_NAVIGATION.md

🔌 API ENDPOINTS:

  POST /api/autonomous/start          Запустить автономное движение
  POST /api/autonomous/stop           Остановить
  GET  /api/autonomous/status         Получить статус

  GET  /api/dual-camera/stream        MJPEG-поток (видео)
  GET  /api/dual-camera/frame         Один кадр (JPEG)
  GET  /api/dual-camera/status        Статус камер

⚙️ МИНИМАЛЬНАЯ КОНФИГУРАЦИЯ:

  RC_AUTO_NAV_ENABLE=1                Включить автономное движение
  RC_ROAD_WIDTH_M=7.5                 Ширина дороги (метры)
  RC_AUTO_NAV_SPEED_MPS=0.08          Скорость (м/с)
  RC_CAMERA_FRONT=/dev/video0         Левая камера
  RC_CAMERA_REAR=/dev/video1          Правая камера
  RC_NAV_MPS_PER_PERCENT=0.01         Калибровка (измерьте!)

🛡️ БЕЗОПАСНОСТЬ:

  Аппаратные меры:
    • E-STOP (физическая + программная кнопка)
    • Watchdog 650 мс (автостоп при потере связи)
    • Проверка свежести данных лидара

  Программные ограничения:
    • Максимальная скорость: 0.15 м/с (540 м/ч)
    • Минимальное расстояние до препятствия: 1.0 м
    • Безопасное расстояние от края дороги: 0.8 м
    • Проверка готовности системы перед стартом

  ⚠ ВАЖНО:
    - Первые тесты с вывешенными колёсами
    - Начинайте с минимальной скорости (0.05 м/с)
    - Всегда держите E-STOP под рукой
    - Не оставляйте робота без присмотра

📞 ПОДДЕРЖКА:

  При возникновении проблем:
    1. Проверьте логи:
       $ tail -f var/logs/robot.log | grep autonomous

    2. Запустите тесты:
       $ python3 scripts/test_autonomous.py --test-full

    3. Изучите документацию:
       $ cat docs/QUICKSTART_AUTONOMOUS.md

  Частые проблемы:
    • Камеры: sudo usermod -aG video $USER (затем выход/вход)
    • Лидар: проверьте RC_LIDAR_PORT в .env
    • Не запускается: RC_AUTO_NAV_ENABLE=1, снять E-STOP

✨ АЛГОРИТМ РАБОТЫ:

  1. ИНИЦИАЛИЗАЦИЯ
     → Запуск объединения камер
     → Проверка лидара и привода

  2. АНАЛИЗ ОКРУЖЕНИЯ (каждые 0.5с)
     → Скан лидара 360°
     → Измерение расстояний до краёв дороги
     → Обнаружение препятствий

  3. ПРИНЯТИЕ РЕШЕНИЯ
     → Препятствие < 1.0м → обход
     → Край < 0.8м → корректировка
     → Иначе → прямо с плавной коррекцией

  4. УПРАВЛЕНИЕ
     → Выставление угла колёс
     → Подача тяги
     → Контроль выполнения

  5. ПОСТРОЕНИЕ КАРТЫ
     → Добавление точек на карту
     → Обновление зон (свободно/занято/неизученно)

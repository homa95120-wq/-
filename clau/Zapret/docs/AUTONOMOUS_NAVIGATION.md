# Автономное движение робота

Система автономного движения позволяет роботу самостоятельно перемещаться по дороге,
избегая препятствий и строя карту окружения.

## Возможности

1. **Автономное движение** — робот самостоятельно едет по дороге, держась в центре
2. **Обход препятствий** — автоматическое обнаружение и обход препятствий
3. **Построение карты** — создание карты местности на основе лидара
4. **Объединение камер** — два изображения с передних камер объединяются в одно широкое

## Железо

### Основные компоненты

- **Процессор**: Intel Core i5-13400 (10 ядер)
- **Память**: 16 ГБ RAM
- **Камеры**: 2× Logitech Brio 500 (передние)
- **Лидар**: RPLIDAR A1/A2/A3 или аналогичный 360°
- **Ширина дороги**: 7.5 метра

### Камеры Logitech Brio 500

Две камеры установлены спереди робота и автоматически объединяются в одно широкое
изображение для улучшенного обзора.

**Характеристики:**
- Разрешение: 1920×1080 (Full HD)
- Частота кадров: 30 FPS
- Интерфейс: USB 3.0
- Автофокус: есть
- Поле зрения: ~90° (каждая камера)

**Подключение:**
- Левая камера: `/dev/video0` (или указать в `RC_CAMERA_FRONT`)
- Правая камера: `/dev/video1` (или указать в `RC_CAMERA_REAR`)

## Настройка

### Переменные окружения

Добавьте в файл `.env`:

```bash
# === Автономное движение ===
# Включить автономное движение
RC_AUTO_NAV_ENABLE=1

# Ширина дороги в метрах (по умолчанию 7.5)
RC_ROAD_WIDTH_M=7.5

# Безопасное расстояние от края дороги в метрах (по умолчанию 0.8)
RC_SAFE_DISTANCE_M=0.8

# Скорость исследования в м/с (по умолчанию 0.08)
RC_AUTO_NAV_SPEED_MPS=0.08

# Интервал обновления сканирования в секундах (по умолчанию 0.5)
RC_SCAN_INTERVAL_S=0.5

# Угол поворота при обходе препятствий в градусах (по умолчанию 30)
RC_TURN_ANGLE_DEG=30.0

# === Камеры ===
# Порты камер (если отличаются от /dev/video0 и /dev/video1)
RC_CAMERA_FRONT=/dev/video0  # Левая камера
RC_CAMERA_REAR=/dev/video1   # Правая камера
```

### Быстрый старт

1. **Установите зависимости** (если ещё не установлены):
   ```bash
   pip install opencv-python numpy
   ```

2. **Настройте окружение** — убедитесь, что в `.env` указаны правильные порты камер
   и включено автономное движение (`RC_AUTO_NAV_ENABLE=1`)

3. **Запустите систему**:
   ```bash
   ./scripts/start_robot.sh
   ```

4. **Откройте веб-интерфейс**:
   ```
   http://<IP-робота>:8080/
   ```

5. **Перейдите в раздел автономного движения** и нажмите **«Запустить»**

## Алгоритм работы

### 1. Анализ окружения

Робот анализирует данные лидара, разделяя пространство на сектора:
- **Передний сектор** (±30°) — проверка препятствий спереди
- **Левый сектор** (60-120°) — измерение расстояния до левого края дороги
- **Правый сектор** (-60 до -120°) — измерение расстояния до правого края дороги

### 2. Принятие решения

На основе анализа робот принимает решение:

- **Нормальное движение** — если дорога свободна и робот в центре
- **Корректировка курса** — если робот слишком близко к краю (< 0.8 м)
- **Обход препятствия** — если обнаружено препятствие ближе 1.0 м

### 3. Управление движением

1. Робот выставляет угол поворота колёс
2. Подаёт тягу на колёса
3. Непрерывно контролирует окружение
4. Обновляет карту местности

### 4. Построение карты

Карта строится автоматически на основе данных лидара:
- Известные свободные области
- Обнаруженные препятствия
- Неизученные зоны

## Безопасность

### Аппаратные меры

- **E-STOP** — аварийная остановка (физическая кнопка + программная)
- **Watchdog** — автоматическая остановка при потере связи (650 мс)
- **Проверка лидара** — движение только при наличии свежего скана

### Программные ограничения

- **Максимальная скорость** — 0.15 м/с (15 см/с)
- **Минимальное расстояние до препятствия** — 1.0 м
- **Безопасное расстояние от края** — 0.8 м
- **Проверка готовности системы** перед каждым запуском

### Что делать в случае проблем

1. **Нажмите E-STOP** — физическую кнопку или в веб-интерфейсе
2. **Остановите автономное движение** — через веб-интерфейс или API
3. **Проверьте журнал** — в веб-интерфейсе или файл логов
4. **Проверьте состояние лидара** — `/api/lidar` или в интерфейсе
5. **Проверьте камеры** — `/api/cameras` или `/api/dual-camera/status`

## Ограничения

1. **Скорость** — максимум 0.15 м/с для безопасности
2. **Ширина дороги** — система рассчитана на дороги 3-15 метров
3. **Препятствия** — обнаруживаются только те, что видит лидар
4. **Освещение** — камеры требуют достаточного освещения
5. **Поверхность** — ровная поверхность, без резких перепадов высот

## Тонкая настройка

### Скорость движения

Если робот движется слишком быстро или медленно:

```bash
# В .env
RC_AUTO_NAV_SPEED_MPS=0.05  # Медленнее
RC_AUTO_NAV_SPEED_MPS=0.12  # Быстрее (макс. 0.15)
```

### Безопасное расстояние

Если робот слишком близко подъезжает к краям:

```bash
# В .env
RC_SAFE_DISTANCE_M=1.2  # Больший запас
```

### Чувствительность поворота

Если робот поворачивает слишком резко или недостаточно:

```bash
# В .env
RC_TURN_ANGLE_DEG=20.0  # Плавнее
RC_TURN_ANGLE_DEG=45.0  # Резче
```

### Частота сканирования

Если нужна более быстрая реакция:

```bash
# В .env
RC_SCAN_INTERVAL_S=0.3  # Чаще (больше нагрузка)
RC_SCAN_INTERVAL_S=1.0  # Реже (меньше нагрузка)
```

# ADR-001: Детерминированное ядро симуляции `simcore` на `Q16.16`

- **Статус:** Принято (M0 → M8)
- **Дата:** 2026-10-25
- **Контекст:** Единое ядро симуляции планеты Серпуло (`simcore`) должно исполняться побитово идентично на ПК (`x86_64`, `ARM64`, GCC/Clang/MSVC) и на микроконтроллере **ESP32-S3 N16R8** (`Xtensa LX7`, ESP-IDF 5.3.x).

## Решение

1. **Полный отказ от `float` / `double` в `simcore/`:**
   - Вся дробная математика выполняется в знаковом фиксированном формате `Q16.16` (`fx32_t = int32_t`, `1.0 = 65536`), промежуточные произведения и деления — через `int64_t`.
   - Квадратный корень (`isqrt64` / `fx_sqrt`) вычисляется целочисленным методом поразрядного уточнения.
2. **Углы и тригонометрия `BAM10`:**
   - Полный оборот $2\pi$ кодируется 10-битным углом `0..1023` (`kTrigLutSize = 1024`).
   - Таблица `kSinLutQ16[1024]` предвычисляется кодогенератором без двоичного `float` (через `decimal.Decimal` высокой точности) и размещается во Flash (`.rodata` / DROM XIP).
3. **Детерминированный ГПСЧ:**
   - Используется `Xorshift64Star` с явным `uint64_t state` внутри `SimHotState` (глобальный `rand()` запрещён).
4. **Строгий порядок обхода и отсутствие кучи:**
   - Все пулы (`buildings[1024]`, `units[256]`, `projectiles[512]`, `cmd_queue[64]`) статического размера и обходятся строго по возрастанию индекса/идентификатора.
   - В `simcore/` запрещены динамические аллокации (`new`, `delete`, `malloc`, `std::vector`, `std::string`), исключения (`-fno-exceptions`) и RTTI (`-fno-rtti`). Контроль обеспечивается CI-скриптом `tools/check_no_float.py`.
5. **Каноническое хеширование состояния:**
   - Функции `sim_state_hash_fnv1a64` и `sim_state_crc32` сериализуют каждое значащее поле `SimWorld` побайтово в явном little-endian порядке, исключая влияние выравнивания (`padding`) разных ABI.

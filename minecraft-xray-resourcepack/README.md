# Anime Girl Blocks — Minecraft Java 1.21.10

Resource pack для Java 1.21.10: **все** стандартные блоки и их иконки в инвентаре
показывают **видео** (15-секундный ролик с двумя девушками и сменными фильтрами),
а **звук из того же видео** играет при разрушении, установке, шагах и ударах по
любым блокам и на всех музыкальных пластинках. При этом блоки **узнаваемы**:
каждое семейство блоков получает собственную анимированную текстуру — кадры
видео затемнены и тонированы в цвет семейства, по краю идёт цветная рамка,
а в центре — пиксельный значок (самоцветы для руд, доски для дерева, замок для
сундука, решётка для стекла…). Блоки сохраняют игровые свойства; формы многих
блоков выглядят как кубы. Текстуры мобов, игроков и предметов, которые не
являются блоками, остаются стандартными. Это шуточный визуальный пак, не ESP
и не чит.

## Установка

1. Скачай `dist/AnimeGirlBlocks-1.21.10.zip` и **не распаковывай**.
2. В Minecraft открой **Настройки → Наборы ресурсов → Открыть папку наборов ресурсов**.
3. Перемести ZIP в эту папку, вернись в игру и включи **Anime Girl Blocks**.
4. Отключи пак в том же меню, чтобы вернуть обычные текстуры и звуки.

## Как это работает

* **Семейства блоков.** `make_block_textures.py` раскладывает все 1166 ID блоков
  по ~490 семействам (`assets/families.json`: таблица правил + значки + цвета).
  Для каждого семейства печатается своя вертикальная полоса кадров
  `assets/families/<семейство>.png`: кадр = кадр видео (уменьшенный, затемнённый
  и тонированный в цвет семейства) + цветная рамка + значок 16×16 с обводкой.
  Частые блоки (камень, земля, руды, дерево, стекло, сундуки…) получают кадры
  32 px и 149 кадров @ 10 fps; остальные — 16 px и 75 кадров @ 5 fps, чтобы пак
  не раздувался и не съедал видеопамять. Цикл анимации у всех примерно 15 с.
* **Значки и цвета.** Значок рисует процедурный пиксель-арт (~95 видов:
  `ore`, `planks`, `log`, `chest`, `furnace`, `rail`, `flower`…); цвет рамки и
  тонировка видео берутся из семейства, поэтому руды алмаза отличаются от руд
  железа и цветом, и формой самоцветов, а красная шерсть — от синей.
  Производные формы (ступени, плиты, заборы, стены, двери…) наследуют семейство
  материала, воск (`waxed_`) и горшки (`potted_`) — семейство базового блока.
* **Факелы, рельсы, колосья и другое — спрайты.** Блоки, которые ваниль рисует
  с cutout (факелы, фонари, рельсы, лестницы, цветы, колосья, грибы, огонь,
  кактусо-подобные силуэты, котлы, наковальни, воронки, рассадники…), получают
  полностью прозрачный фон и один значок: в мире они выглядят как силуэт
  своего блока, а не как opaque-куб с видео. Список семейств —
  `SPRITE_FAMILIES` в `make_block_textures.py`.
* **Стекло и лёд честно прозрачные.** У семейства стекла середина кадра
  прозрачная, а блоки стекла в игре и так рисуются с cutout — поэтому стекло
  остаётся стеклом: рамка + блик, сквозь которые видно мир, а видео играет в
  кайме и блике. Лёд полупрозрачный (translucent).
* **Вода и лава** — отдельные запечённые полосы 32 px из того же клипа:
  `assets/anime_girl_water.png` (видео + синева + капля) и
  `assets/anime_girl_lava.png` (видео + оранжевый + пламя). Они же лежат в пяти
  ванильных текстурах жидкостей (`water_still/flow/overlay`, `lava_still/flow`),
  поэтому и поверхность жидкости, и «куб» воды показывают ролик.
* **Невидимые блоки** (воздух пещер, barrier, structure_void…) получают полностью
  прозрачную текстуру, чтобы пак не рисовал кубы там, где раньше был воздух.
* **Звук:** `assets/video.ogg` (моно Ogg Vorbis, 14,9 с) подключён через
  `sounds.json` с `"replace": true` к 559 ванильным событиям блоков
  (`block.*` — break/place/step/hit/fall у 118 групп материалов) и ко всем 21
  пластинкам (`music_disc.*`, со стримингом) — 580 событий. Список событий — в
  `sound_events.json`, он взят из ванильного `sounds.json` версии 1.21.10.
* **pack.png** — отдельный кадр-постер (`assets/poster.png`), иконке набора
  анимация не нужна.

### Про звук на блоках честно

Каждое действие **запускает дорожку заново**: идёшь по траве — шаги накладывают
копии друг на друга. Это часть шутки, но если хаоса станет слишком много, в
`build.py` есть ручки: уберите `"step"` из `BLOCK_SOUND_VERBS` (останутся
разрушение/установка/удары), выключите `ENABLE_BLOCK_SOUNDS` (останутся только
пластинки) или `ENABLE_DISC_SOUNDS` — и пересоберите пак. Таймер проигрывателя
при этом ванильный: игра считает, что пластинка играет свою обычную длину,
хотя звук заканчивается через 14,9 с.

## Своё видео

```sh
pip install pillow imageio-ffmpeg   # или поставьте ffmpeg в систему
python3 make_animated_texture.py /path/to/video.mov
python3 make_block_textures.py      # перепечатает семейства из новой полосы кадров
python3 build.py
```

`make_animated_texture.py` вырезает квадрат из видео (`--crop-pos 0..1` — позиция
вдоль длинной стороны, по умолчанию 0.36: чуть выше центра, чтобы влезали оба
лица), собирает полосу кадров (`--size`, `--fps` — должен делить 20), уменьшенную
копию для жидкостей (`--fluid-size`), кадр-постер и `video.ogg`, подрезанный
ровно под длину цикла анимации.

`make_block_textures.py` читает полосу `assets/anime_girl.png` и таблицу
семейств из самого скрипта (правила — списком регулярок, значки — функции
`g_*`), печатает полосы семейств в `assets/families/`, полосы воды/лавы и
`assets/families.json` для сборщика и превью. Хочешь новое семейство или свой
значок — добавь правило/функцию туда и перезапусти оба скрипта.

## Сборка и проверка

```sh
python3 build.py
```

Скрипт (только стандартная библиотека, ffmpeg и Pillow не нужны) создаёт
`dist/AnimeGirlBlocks-1.21.10.zip` и проверяет: что каждый блок получил
семейство и полосу нужной геометрии (ширина/высота/число кадров сверяются с
`families.json`), что каждый blockstate ссылается на существующую в архиве
модель, что воздух не заменён, заголовок Ogg и все JSON/`.mcmeta` внутри.

Превью в браузере: `dist/preview.html` (открой через локальный сервер из корня
этой папки, например `python3 -m http.server`, затем
`http://localhost:8000/dist/preview.html`) — живая галерея всех семейств с
анимацией настоящих текстур пака, поиском по блокам и плеером звука видео.

# Anime Girl Blocks — Minecraft Java 1.21.10

Resource pack для Java 1.21.10: заменяет **все** стандартные блоки и их иконки в инвентаре **анимированной текстурой из видео** (15-секундный ролик с двумя девушками и сменными фильтрами) — включая руды, сундуки, воду и лаву. **Звук из того же видео** играет при разрушении, установке, шагах и ударах по любым блокам, а также на всех музыкальных пластинках в проигрывателе. Блоки сохраняют игровые свойства, но формы многих блоков выглядят как кубы. Текстуры мобов, игроков и предметов, которые не являются блоками, остаются стандартными. Это шуточный визуальный пак, не ESP и не чит.

## Установка

1. Скачай `dist/AnimeGirlBlocks-1.21.10.zip` и **не распаковывай**.
2. В Minecraft открой **Настройки → Наборы ресурсов → Открыть папку наборов ресурсов**.
3. Перемести ZIP в эту папку, вернись в игру и включи **Anime Girl Blocks**.
4. Отключи пак в том же меню, чтобы вернуть обычные текстуры и звуки.

## Как это работает

- **Анимация:** `assets/anime_girl.png` — вертикальная полоса из 149 кадров 128×128, рядом лежит `anime_girl.png.mcmeta` с `frametime: 2` (2 игровых тика = 10 fps). Цикл длится ровно 14,9 с — столько же, сколько звуковая дорожка. Ванильный Minecraft не умеет перезапускать анимацию текстуры по событию, поэтому фаза ролика глобальная; зато длины цикла и звука совпадают до десятой секунды и не расходятся со временем.
- **Вода и лава** используют уменьшенную полосу 32×32 (`assets/anime_girl_fluid.png`) с той же анимацией: жидкости в игре тонируются и искажаются, а одна и та же текстура кладётся в пак пять раз.
- **Звук:** `assets/video.ogg` (моно Ogg Vorbis, 14,9 с) подключён через `sounds.json` с `"replace": true` к 559 ванильным событиям блоков (`block.*` — break/place/step/hit/fall у 118 групп материалов) и ко всем 21 пластинкам (`music_disc.*`, со стримингом). Список событий — в `sound_events.json`, он взят из ванильного `sounds.json` версии 1.21.10.
- **pack.png** — отдельный кадр-постер (`assets/poster.png`), иконке набора анимация не нужна.

### Про звук на блоках честно

Каждое действие **запускает дорожку заново**: идёшь по траве — шаги накладывают копии друг на друга. Это часть шутки, но если хаоса станет слишком много, в `build.py` есть ручки: уберите `"step"` из `BLOCK_SOUND_VERBS` (останутся разрушение/установка/удары), выключите `ENABLE_BLOCK_SOUNDS` (останутся только пластинки) или `ENABLE_DISC_SOUNDS` — и пересоберите пак. Таймер проигрывателя при этом ванильный: игра считает, что пластинка играет свою обычную длину, хотя звук заканчивается через 14,9 с.

## Своё видео

```sh
pip install pillow imageio-ffmpeg   # или поставьте ffmpeg в систему
python3 make_animated_texture.py /path/to/video.mov
python3 build.py
```

`make_animated_texture.py` вырезает квадрат из видео (`--crop-pos 0..1` — позиция вдоль длинной стороны, по умолчанию 0.36: чуть выше центра, чтобы влезали оба лица), собирает полосу кадров (`--size`, `--fps` — должен делить 20), уменьшенную копию для жидкостей (`--fluid-size`), кадр-постер и `video.ogg`, подрезанный ровно под длину цикла анимации.

## Сборка и проверка

```sh
python3 build.py
```

Скрипт (только стандартная библиотека, ffmpeg не нужен) создаёт `dist/AnimeGirlBlocks-1.21.10.zip` и проверяет: геометрию полос кадров и равенство числа кадров, `frametime`, заголовок Ogg, структуру архива и все JSON/`.mcmeta` внутри.

Превью в браузере: `dist/preview.html` (открой через локальный сервер из корня этой папки, например `python3 -m http.server`) — там живая анимация полосы кадров и плеер со звуком.

      ESP32 Studio

      Редактор в стиле VS Code для программирования ESP32 на MicroPython прямо из браузера.

      • ⚡ Подключить — выбери USB-порт платы (нужен Chrome / Edge / Opera)
      • ▶ F5 — запустить открытый файл на плате
      • ⬆ Ctrl+U — сохранить файл на плату (main.py запустится при включении)
      • Ctrl+Shift+P — палитра команд

      Нет MicroPython на плате? Вкладка ⚡ слева — прошивка за минуту.

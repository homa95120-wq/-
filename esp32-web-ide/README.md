# ESP32 Studio

IDE в стиле Visual Studio Code для программирования ESP32 / ESP32-S3 на MicroPython —
**прямо в браузере, без установки**. Плата подключается по USB через Web Serial.

![layout](https://img.shields.io/badge/UI-VS%20Code%20Dark%2B-0078d4) ![mpy](https://img.shields.io/badge/MicroPython-ESP32%20%7C%20S3%20%7C%20C3-blue)

## Что умеет

| | |
|---|---|
| **Редактор Monaco** | тот же движок, что в VS Code: подсветка, автодополнение MicroPython (`machine`, `Pin`, `network`…), сниппеты, миникарта, мультикурсор |
| **▶ Запуск (F5)** | выполняет открытый файл на плате, вывод в терминал |
| **⬆ Загрузка (Ctrl+U)** | записывает файл на флеш платы; `main.py` стартует при включении |
| **Файлы на плате** | просмотр, открытие, редактирование, удаление, копирование в проект |
| **Терминал REPL** | полноценный xterm: Ctrl+C, Ctrl+D, автодополнение Tab и т.д. |
| **⚡ Прошивка** | заливает MicroPython `.bin` через esptool-js, автоопределение чипа и адреса (0x0 для S3/C3, 0x1000 для ESP32), показывает статус «Идёт прошивка» и полный журнал |
| **⬇ Обновить с GitHub** | проверяет официальный релиз `esp32-studio-latest` по идентификатору сборки/коммита и даёт скачать подходящий Windows `.exe` (Setup или Portable) |
| **Проект в браузере** | файлы хранятся в localStorage, переживают перезагрузку |
| **Примеры** | мигание, RGB-светодиод S3, Wi-Fi сканер, веб-сервер, кнопка, АЦП/ШИМ, I2C-сканер |
| **Палитра команд** | Ctrl+Shift+P, как в VS Code; меню, контекстные меню, статус-бар |

## Приложение (Windows / Linux / macOS)

Готовые сборки: вкладка **Releases** на GitHub → `ESP32 Studio Setup.exe` (установщик)
или `ESP32-Studio-portable.exe` (просто запустить). Собираются автоматически при каждом изменении в `main`.

Собрать самому:

```bash
cd esp32-web-ide
npm install
npm run app        # запустить приложение
npm run dist:win   # собрать .exe (release/)
```

Внутри Electron: тот же интерфейс, Web Serial работает «из коробки», выбор COM-порта —
своё окно в стиле VS Code, список обновляется при подключении платы.

## Веб-версия (разработка)

```bash
cd esp32-web-ide
npm install
npm run dev        # http://localhost:5173
```

Сборка статики: `npm run build` → папка `dist/`, можно положить на любой хостинг с HTTPS
(Web Serial работает только по HTTPS или на localhost). В репозитории есть workflow для GitHub Pages.

**Браузер:** Chrome, Edge, Opera (десктоп или Android). Firefox и Safari Web Serial не поддерживают.

## Первый запуск с платой

1. Подключи ESP32 по USB. На Windows может понадобиться драйвер CP210x / CH340
   (ESP32-S3 через встроенный USB — драйвер не нужен).
2. Если на плате ещё нет MicroPython: вкладка **⚡** → выбери `.bin` с
   [micropython.org](https://micropython.org/download/?port=esp32) (для S3 — `ESP32_GENERIC_S3`) → **Прошить**.
   Если плата не входит в режим загрузки — зажми BOOT, нажми RESET, отпусти BOOT.
3. Нажми **⚡ Подключить**, выбери порт.
4. Открой `main.py`, F5 — программа запустится. Ctrl+U — записать на плату навсегда.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| F5 / Shift+F5 | Запустить / остановить |
| Ctrl+U | Загрузить файл на плату |
| Ctrl+Shift+C | Подключить / отключить |
| Ctrl+Shift+R | Мягкий сброс платы |
| Ctrl+N / Ctrl+O | Новый файл / открыть с компьютера |
| Ctrl+Shift+P, F1 | Палитра команд |
| Ctrl+B / Ctrl+J | Боковая / нижняя панель |

## Как устроено

```
electron/
  main.cjs     окно приложения, схема app://, обработка Web Serial
  preload.cjs  диалог выбора порта
src/
  main.js      UI: вкладки, проводник, палитра, меню, настройки, статусы и окно обновлений
  device.js    Web Serial + протокол raw REPL MicroPython (exec, run, файлы, диагностика таймаутов)
  updater.js   проверка релиза esp32-studio-latest на GitHub по коммиту сборки и метаданным
  flasher.js   прошивка через esptool-js
  examples.js  примеры кода
  style.css    тема VS Code Dark+
```

Файлы передаются на плату через raw REPL в base64 кусками по 768 байт — работает на любой
прошивке MicroPython без WebREPL и дополнительных модулей.

## ESP32-S3 N16R8 / CH343 (COM7)

- Подключай кабель с данными к **COM**. CH343 использует VID `1A86`; приложение
  показывает все COM-порты, а не только известные VID. Номер COM может отличаться.
- Если список пуст: проверь кабель, разъём и драйвер CH343 в Диспетчере устройств.
- Статусы подключения различаются явно:
  - **«⚡ Идёт прошивка»** — порт занят загрузчиком `esptool-js`;
  - **«🔌 COM открыт»** — последовательный порт открыт, идёт проверка REPL;
  - **«⚡ MicroPython готов»** — получен ответ от MicroPython REPL;
  - **«⚠ Нет ответа REPL (COM открыт)»** — порт открыт, но плата не ответила на запрос raw REPL.
- Запуск программы (`▶`) отмечается как выполняющийся только после подтверждения `OK` от raw REPL.
- Отсутствие ответа REPL на COM-порту **не доказывает**, что MicroPython не установлен:
  на платах ESP32-S3 с двумя USB-C разъёмами (`COM` и `USB`) загрузчик всегда работает
  на **COM (CH343, VID `1A86`)**, а консоль REPL MicroPython может быть выведена на
  встроенный разъём **USB (Espressif USB-CDC, VID `303A`)**.
- Не выполняй повторное стирание флеш без необходимости — стирание безвозвратно удаляет все файлы и данные на плате.

### Первая прошивка

1. Скачай официальный `.bin` для **ESP32_GENERIC_S3**, вариант
   **SPIRAM_OCT** (имя `ESP32_GENERIC_S3-SPIRAM_OCT-…bin`) с
   https://micropython.org/download/ESP32_GENERIC_S3/ — для 8 МБ Octal PSRAM.
2. Открой вкладку **⚡**, выбери файл, адрес **0x0** (или авто), скорость
   **115200**, если на высокой скорости возникают ошибки.
3. Стирание флеш удаляет файлы и настройки платы — сохрани нужные данные заранее.
4. Нажми **Прошить**, выбери COM7. Если загрузчик не отвечает:
   зажми BOOT, нажми и отпусти RESET, отпусти BOOT и повтори прошивку.
5. После записи нажми RESET, если требуется. Программа повторно откроет порт.
   Если COM открыт, но REPL не отвечает, попробуй разъём **USB** и выбери новый
   порт Espressif: в некоторых сборках S3 консоль доступна на встроенном USB,
   а COM/CH343 остаётся доступным для загрузчика.

Для сообщения об ошибке укажи: `.exe`/portable/Chrome, виден ли диалог и COM7,
текст терминала и имя установленного `.bin`.

Проверки без платы: `node --test tests/*.test.cjs`, затем `npm run build`.
Физическое подключение, BOOT/RESET и прошивку нужно проверить на самой плате Windows.

# Протокол клиент-сервер — esp32s3-mindustry-serpulo

**ESP32-S3 = сервер симуляции (headless), ПК = клиент (отображение + ввод).**
Связь: Wi-Fi TCP-сокет (ESP32-S3 — сервер, ПК — клиент) или опционально USB-CDC.

> Статус: черновик спецификации. Требует уточнения перед реализацией этапа 4.

## Формат сообщений

Все сообщения — бинарные, little-endian, с фиксированным заголовком:

```
| magic (2) | type (1) | seq (2) | len (2) | payload (len) | crc16 (2) |
```

- `magic = 0x4D53` ("MS" — MindSerpulo)
- `type`: 0x01 состояние сектора (сервер→клиент), 0x02 команда ввода (клиент→сервер), 0x03 KeepAlive
- `seq`: порядковый номер для контроля доставки
- `crc16`: CRC-CCITT над всем сообщением без поля crc

## Состояние сектора (сервер → клиент)

Отправляется каждый тик симуляции (или при изменении). Содержит:

- номер тика, номер волны, время до следующей волны
- список активных зданий: id, тип блока, координаты (тайл), HP, состояние
- список активных юнитов: id, тип юнита, координаты, HP, цель, состояние
- список пуль/снарядов: id, позиция, скорость, урон
- состояние электрической сети: баланс за тик, заряд батарей
- ресурсы игрока (предметы, жидкости) на ядре
- флаги: игра окончена, сектор захвачен, нужна помощь

## Команда ввода (клиент → сервер)

Отправляется при действии игрока:

- постройка блока: тип блока, координаты тайла
- удаление блока: координаты тайла
- перемещение выделенного юнита: целевые координаты
- атака цели: id цели
- skip wave (запуск следующей волны)
- пауза / продолжение симуляции

## Отличия от оригинальной Mindustry

- Это не сетевой протокол Mindustry (Netty). Не совместим с мультиплеером оригинала.
- Не поддерживает моды оригинала.
- Сохранения — собственные форматы, не `.msav`.

## Открытые вопросы

1. Частота отправки состояния (каждый тик или при изменении) — зависит от пропускной способности Wi-Fi.
2. Сжатие состояния (дельта-обновления vs полная посылка).
3. Порт TCP по умолчанию (предложение: 26789).
4. Аутентификация / шифрование — не требуется для локальной сети, но можно добавить later.

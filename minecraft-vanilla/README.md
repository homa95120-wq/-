# FreeView Vanilla — Minecraft Java 1.21.10

Это **datapack без Forge, Fabric и других модлоадеров**. Он даёт только близкие ванильные альтернативы исходным функциям; datapack не умеет назначать клиентские клавиши `R`, `[` и `]` или перемещать отдельную камеру, оставляя персонажа на месте.

## Команды

Запускайте их **из игры от имени игрока**:

| Команда | Результат и ограничение |
|---|---|
| `/function freeview:help` | Показать справку |
| `/function freeview:camera` | Перейти в spectator: можно летать и проходить сквозь блоки, но персонаж становится наблюдателем. Это не freecam с неподвижным персонажем. |
| `/function freeview:survival` | Перейти в Survival |
| `/function freeview:flight_on` | Перейти в Creative. Полёт серверный и виден другим, но вместе с ним выдаются стандартные возможности творческого режима. |
| `/function freeview:flight_off` | Перейти в Survival. Исходный режим автоматически не сохраняется. |
| `/function freeview:glow_on` | Дать эффект свечения **всем игрокам на сервере**. Контуры видят все, это не персональный ESP. |
| `/function freeview:glow_off` | Снять эффект свечения со всех игроков. |

Нужны включённые читы в одиночном мире или права оператора на сервере. Функции `glow_on` и `glow_off` меняют эффект у всех игроков; команда выключения также снимет обычный эффект `Glowing`, если он был выдан другим способом.

## Установка

1. Скопируйте `FreeViewVanilla-1.21.10.zip` в папку `datapacks` нужного мира. На сервере это `world/datapacks/` (имя папки мира может отличаться).
2. Выполните `/reload` или перезапустите мир/сервер.
3. Проверьте загрузку через `/datapack list`, затем выполните `/function freeview:help`.

Архив для установки находится в `dist/FreeViewVanilla-1.21.10.zip`. Его можно пересобрать командой:

```sh
python3 build.py
```

Результат: `dist/FreeViewVanilla-1.21.10.zip`.

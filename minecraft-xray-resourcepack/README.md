# ClientSeeThrough — Minecraft Java 1.21.10

Клиентский resource pack для чистой Java-версии Minecraft: модлоадер не нужен, сервер менять не нужно. Он заменяет модели всех стандартных блоков пустыми и делает текстуры воды/лавы прозрачными. Из-за этого игроки и другие сущности за блоками могут стать видны на твоём экране.

**Это не настоящий ESP:** контуров и клавиш-переключателей нет, а почти весь мир станет невидимым. Блоки останутся на месте и коллизия сохранится. Пак не даёт полёт и не меняет данные сервера. На многопользовательских серверах такой ресурс-пак может нарушать правила — используй его только если это разрешено.

## Установка на клиент

1. Скачай `dist/ClientSeeThrough-1.21.10.zip` и **не распаковывай**.
2. В Minecraft открой **Настройки → Наборы ресурсов → Открыть папку наборов ресурсов**.
3. Перемести ZIP в открывшуюся папку, вернись в игру и включи **ClientSeeThrough**.
4. Чтобы вернуть обычный вид, отключи этот набор в том же меню.

Загружать ZIP на Aternos не нужно. Сервер остаётся vanilla; изменения видны только на клиенте, где включён набор. Он рассчитан на Java 1.21.10.

## Сборка и проверка

```sh
python3 build.py
```

Скрипт создаёт `dist/ClientSeeThrough-1.21.10.zip` и проверяет структуру архива и JSON-файлы.

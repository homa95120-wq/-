# 📦 СПИСОК СОЗДАННЫХ ФАЙЛОВ

Все файлы для автономного движения робота.

## 🎯 Основные модули (Python)

### 1. `robot_control/dual_camera_merger.py` (233 строки)
**Назначение**: Объединение изображений с двух камер Logitech Brio 500

**Содержимое**:
- Класс `DualCameraMerger` — основной класс для объединения
- Захват с двух камер через OpenCV
- Объединение с плавным переходом в зоне перекрытия (10%)
- MJPEG кодирование для стриминга
- Фоновый поток для непрерывной работы
- Функции `get_merger()` и `reset_merger()` для глобального доступа

**Ключевые параметры**:
- Разрешение: 1920×1080
- FPS: 30
- Качество JPEG: 85%
- Зона перекрытия: 10%

---

### 2. `robot_control/autonomous_navigation.py` (390 строк)
**Назначение**: Автономное движение робота с построением карты

**Содержимое**:
- Класс `AutonomousNavigationService` — основной сервис
- Класс `AutonomousNavigationError` — специфичные ошибки
- Анализ окружения на основе лидара (360°)
- Принятие решений (прямо/корректировка/обход)
- Управление движением (руль + тяга)
- Автоматическое построение карты
- Безопасные проверки перед стартом

**Ключевые параметры**:
- Скорость: 0.02-0.15 м/с (по умолчанию 0.08)
- Ширина дороги: 3-15 м (по умолчанию 7.5)
- Безопасное расстояние: 0.3-2.0 м (по умолчанию 0.8)
- Интервал сканирования: 0.2-2.0 с (по умолчанию 0.5)
- Угол поворота: 15-90° (по умолчанию 30)

---

### 3. `robot_control/autonomous_api.py` (105 строк)
**Назначение**: Flask Blueprint с API эндпоинтами

**Содержимое**:
- Функция `create_autonomous_blueprint()` — создание Blueprint
- **GET** `/api/autonomous/status` — статус автономного движения
- **POST** `/api/autonomous/start` — запуск
- **POST** `/api/autonomous/stop` — остановка
- **GET** `/api/dual-camera/status` — статус камер
- **GET** `/api/dual-camera/stream` — MJPEG-поток
- **GET** `/api/dual-camera/frame` — отдельный кадр

**Форматы ответов**: JSON (статус) и multipart/x-mixed-replace (видео)

---

### 4. `robot_control/autonomous_integration_example.py` (230 строк)
**Назначение**: Пример интеграции в основное приложение

**Содержимое**:
- Функция `integrate_autonomous_navigation()` — интеграция сервисов
- Пример кода для `app.py`
- Пример полей для `Config` класса
- Готовая HTML-страница с интерфейсом управления
- JavaScript для взаимодействия с API
- CSS стили (тёмная тема)

**Особенности**:
- Живое обновление статуса (каждую секунду)
- Показатели: расстояние, время, препятствия, скорость
- Визуализация фаз (idle, exploring, avoiding и т.д.)
- Просмотр объединённого видео с камер

---

### 5. `scripts/test_autonomous.py` (185 строк, executable)
**Назначение**: Тестирование всех компонентов системы

**Содержимое**:
- `test_cameras()` — проверка доступности камер
- `test_merge()` — тест объединения изображений
- `test_lidar()` — проверка работы лидара
- `test_full()` — полный тест всей системы
- Аргументы командной строки: `--test-cameras`, `--test-merge`, `--test-lidar`, `--test-full`

**Использование**:
```bash
python3 scripts/test_autonomous.py --test-full
```

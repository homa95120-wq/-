# Campaign Threat Radar (v1.3)

Клиентский тактический HUD-мод для **Mindustry v8** (билды 154+).

Размещается в **верхнем правом углу (левее миникарты)**, ведет учет вражеских сил, показывает **мини-карту с врагами** вокруг вашего ядра и заранее предупреждает обо всех угрозах и сбоях базы с помощью встроенного диагностического алгоритма.

Мод помечен как `hidden: true` — он является **чисто клиентским**, не создает сущностей, не меняет правила мира, не шлет сетевых пакетов и **не влияет на сервер** (вы можете свободно заходить на любые многопользовательские сервера и играть в кампанию).

## 🎯 Возможности мода

1. **Мини-карта с врагами (новая):**
   - 🔵 Синие квадраты — ваши ядра, ⚪ белая точка — вы.
   - 🔴 Красные точки — наземные враги, 🟠 оранжевые — авиация, 🔴 с кольцом — боссы.
   - Радар вращается вокруг самого слабого ядра (то есть вокруг места, куда придёт удар) и показывает радиус **120 блоков**.
   - Враги за пределами радиуса отображаются стрелками на краю — видно, с какой стороны идёт волна.
   - Пунктирная линия показывает направление на ближайшую угрозу.

2. **Реалистичные предсказания (переработаны):**
   - ⏱ **ETA считается по реальной скорости типа юнита**, а не по текущей мгновенной скорости: юнит, который только что появился или стоит в бою, больше не даёт бессмысленных «ETA 500 с».
   - 📐 Учитываются: обход препятствий наземными юнитами (+30 % пути), разгон после старта, потери времени на разворот и на добивание текущей цели (+2–3 с).
   - 📊 Показывается **диапазон** ETA («12–18 с»), а не одно число: оценка честно отражает неопределенность.
   - 🔮 **Прогноз атаки:** сколько врагов и с каким уроном подойдут к ядру за 60 с, через сколько ядро ляжет, и хватит ли вашей обороны.
   - 🛡 Считается реальный DPS ваших турелей (`estimateDps()`) и сравнивается с DPS врага.
   - 🟠 Враги, которые идут в обход, тоже прогнозируются — с задержкой, а не игнорируются.

3. **Счетчик и состав вражеских сил:**
   - Общее количество вражеских юнитов на карте.
   - Разбивка по типам: 🚜 Наземные юниты и 🛸 Воздушная авиация.
   - Обнаружение 💀 Боссов и супер-юнитов (T4/T5) с указанием их имен.

4. **Интеллектуальный алгоритм предупреждения угроз и сбоев:**
   - ⚠️ **Угроза прорыва к ядру (ETA):** расчет времени подхода врагов к ближайшему ядру игрока в секундах (с диапазоном).
   - 🚨 **Опасная близость:** оповещение, если враги подобрались вплотную к ядру (< 40 блоков).
   - 💀 **Босс-алерт:** индикация присутствия мощных боссов на поле боя.
   - 🚨 **Состояние Ядра:** предупреждение о повреждении ядра и критическом уровне HP.
   - ⚡ **Диагностика энергосети:** расчет дефицита энергии (нетто кВт/с), процент заряда аккумуляторов и оповещение об угрозе блэкаута.
   - 📦 **Боезапас турелей:** подсчет турелей, оставшихся без патронов/снарядов.
   - 🛠️ **Повреждения базы:** индикация критически поврежденных строений обороны.
   - ✅ **Все системы стабильны:** статус при отсутствии угроз и врагов.

5. **Удобный интерфейс:**
   - Расположен вверху справа, левее миникарты, с увеличенным отступом (150 + 70 UI units), поэтому панель **не перекрывает** миникарту даже на узких экранах.
   - Полупрозрачный темный фон (`Styles.black8`), клики сквозь панель не блокируются (`Touchable.disabled`).

## 📦 Сборки

Есть две равноценные по логике версии (ставьте и включайте **только одну**):

| Файл | Что это | Как работает |
|---|---|---|
| `CampaignThreatRadar.jar` | Java-мод (Java 17) | Рекомендуемая основная сборка |
| `CampaignThreatRadar.zip` | Скриптовый мод (Rhino JS API) | Скриптовый архив (`Campaign Threat Radar (ZIP)`), Java не требуется |

## 🚀 Установка

### Вариант 1: Через меню игры (самый простой, для jar)
1. В игре перейдите в **Моды** → **Импорт** → **Импорт из GitHub**.
2. Введите репозиторий: `homa95120-wq/-` (название репозитория — это буквально дефис).
3. Игра автоматически скачает актуальный `.jar` из последнего релиза.

### Вариант 2: Вручную через архив
1. Скачайте файл `CampaignThreatRadar.jar` из Releases или `dist/CampaignThreatRadar.zip` из репозитория.
2. Положите файл (целиком архив, **НЕ распаковывая!**) в папку `mods`:
   - **Steam (любая ОС):** `<папка игры>\saves\mods\` (например `...\steamapps\common\Mindustry\saves\mods\`)
   - **Windows:** `%APPDATA%\Mindustry\mods\`
   - **Linux:** `~/.local/share/Mindustry/mods/`
   - **macOS:** `~/Library/Application Support/Mindustry/mods/`
3. Перезапустите Mindustry, убедитесь, что мод включен в списке модов, и запустите игру/кампанию.

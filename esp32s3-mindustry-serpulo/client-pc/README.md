# `client-pc` — Нативная ПК-версия Mindustry: Serpulo (SDL2 + OpenGL 3.3)

Графическое приложение `mindustry-serpulo-pc` объединяет **два режима** в одном исполняемом файле:

1. **Автономная игра на ПК (Путь A):**
   - Внутри процесса работает детерминированное ядро `simcore` (`Q16.16`, 60 TPS / 60 FPS).
   - Доступны все **29 именованных секторов Серпуло** (`M`), добыча руд, заводы, конвейеры/маршрутизаторы/мосты, трубы/помпы, энергосеть, стены и турели, волны врагов Crux, сохранения `.msv1` (`F5`/`F9`).
2. **Удалённый клиент к плате ESP32-S3 (Путь B):**
   - Подключение по **Wi-Fi TCP** (`--tcp 192.168.4.1:26789` или клавиша `F2` в игре) либо по **USB-CDC / UART** (`--serial COM7` или `--serial /dev/ttyACM0`).
   - Обмен по бинарному протоколу `0x4D53` с проверкой `CRC16-CCITT` и плавной интерполяцией позиций юнитов/снарядов с 30 Гц до 60 FPS.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки / СКМ | Перемещение камеры |
| Колесо мыши | Масштаб (`6..64` пикс/тайл) |
| `ЛКМ` (и протяжка) | Постройка блока (с автоповоротом конвейеров и труб) |
| `ПКМ` (и протяжка) | Снос постройки (с возвратом 50% ресурсов) |
| `1`..`7` | Категории блоков (Буры, Конвейеры, Жидкости, Энергия, Заводы, Стены, Турели) |
| `R` | Поворот блока |
| `Space` | Досрочный запуск следующей волны |
| `P` | Пауза симуляции |
| `M` | Карта выбора 29 секторов Серпуло |
| `B` | Переключение режима Песочница (бесплатная постройка) |
| `F2` | Подключение / отключение от сервера ESP32-S3 (`0x4D53`) |
| `F5` / `F9` | Сохранение / загрузка сектора (`serpulo_save.msv1`) |
| `F3` / `G` / `L` | Дебаг-телеметрия / Сетка тайлов / Язык интерфейса `RU` ↔ `EN` |

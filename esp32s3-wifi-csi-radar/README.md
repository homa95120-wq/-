# ESP32-S3 Wi-Fi CSI «радар»

Детектор движения в комнате **без единого датчика** — только ESP32-S3 и его Wi-Fi.
Плата слушает, как радиосигнал отражается от стен и людей (CSI — Channel State Information),
и показывает в браузере радарный экран: тихо / шевеление / движение.

> Честно о возможностях: это **не карта комнаты**. Стены таким способом не увидеть.
> Зато присутствие и движение человека ловится уверенно, даже за тонкой перегородкой.

## Что нужно

- ESP32-S3 (любая плата: DevKitC, Super Mini, с PSRAM или без — не важно)
- Arduino IDE 2.x с пакетом **esp32 by Espressif Systems 3.x**
- Wi-Fi-роутер (желательно) — или просто телефон

Внешних библиотек ставить не надо.

## Прошивка

1. Открой `esp32s3_csi_radar/esp32s3_csi_radar.ino` в Arduino IDE.
2. Впиши свой Wi-Fi в `WIFI_SSID` / `WIFI_PASS`.
   Если оставить пустым — плата поднимет свою точку `CSI-Radar` (пароль `12345678`).
3. Плата: **ESP32S3 Dev Module**. USB CDC On Boot: **Enabled** (чтобы видеть Serial).
4. Залей, открой Serial Monitor (115200) — там будет IP-адрес.
5. Открой этот адрес в браузере с телефона/ноутбука.
6. Первые 5 секунд **не двигайся** — идёт калибровка фона. Потом походи по комнате.

## Что на экране

| Элемент | Что значит |
|---|---|
| Радарный круг | растёт и краснеет при движении, жёлтые «отметки» — всплески |
| График | метрика движения за 30 сек, красный пунктир — порог срабатывания |
| Спектр | амплитуда ~64 поднесущих CSI в реальном времени — «отпечаток» комнаты |
| Кнопка | перекалибровка, если переставил плату или поменялась обстановка |

Также в Serial Plotter рисуются `motion` и `threshold`.

## Как это работает

1. Плата пингует роутер 20 раз/сек. На каждый ответ Wi-Fi-чип отдаёт CSI —
   комплексную амплитуду для каждой поднесущей OFDM (64 для 20 МГц канала).
2. Амплитуды нормируются (чтобы не мешала автоподстройка усиления).
3. Считается среднее отклонение текущего кадра от медленно плывущего фона.
   Неподвижная комната даёт маленькое, стабильное число; человек в движении — всплески.
4. Порог = фон при калибровке × 2.5.

В режиме точки доступа (без роутера) трафик создаёт сам браузер, опрашивая `/data` каждые 100 мс.
Работает хуже, чем с роутером, но работает.

## Советы

- Лучшая чувствительность — когда человек проходит **между** платой и роутером.
- 2.4 ГГц, 20 МГц канал. На 5 ГГц ESP32-S3 не умеет.
- Если «движение» срабатывает само — подвинь плату подальше от микроволновки/вентилятора,
  отключи в роутере band steering, нажми перекалибровку.
- Кабель USB в ноутбук лучше заменить на зарядку в розетку: ноутбук сам шевелится.
- Две-три платы в разных углах + сравнение метрик дают грубое представление, **где** движение.

## API

- `GET /data` — JSON: `motion`, `level` (кратность порога), `rssi`, `frames`, `hist[300]`, `amps[]`
- `GET /calib` — запустить калибровку заново

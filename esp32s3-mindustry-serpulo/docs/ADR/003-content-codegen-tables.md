# ADR-003: Кодогенерация таблиц контента Серпуло во Flash (`.rodata` / XIP)

- **Статус:** Принято (M0 → M8)
- **Дата:** 2026-10-25
- **Контекст:** Контент Mindustry `v160.7` (коммит `17012d61d9e4c3cbd9820d87e81c24495486ac53`) содержит дробные характеристики предметов, жидкостей, блоков, юнитов и секторов. Ручной пересчёт в `Q16.16` подвержен ошибкам округления, а хранение таблиц в RAM недопустимо для бюджета SRAM ESP32-S3.

## Решение

1. Первоисточники параметров хранятся в JSON-реестрах `content/data/*.json` (`items.json`, `liquids.json`, `blocks.json`, `units.json`, `sectors.json`), где дробные величины записаны точными десятичными строками (`"0.5"`, `"1.15"`, `"0.0801"`).
2. Скрипт `tools/codegen/gen_content.py` переводит десятичные строки в `fx32_t` (`Q16.16`) через точную рациональную арифметику `fractions.Fraction(value) * 65536` с детерминированным округлением half-away-from-zero без участия `float`.
3. Генерируемые C++ заголовки в `simcore/include/simcore/generated/*.hpp` объявляют таблицы как `inline constexpr` структуры POD-типа, которые компилятор `xtensa-esp32s3-elf-g++` кладёт напрямую в секцию `.rodata` (DROM XIP во Flash 16 МБ) с **нулевым расходом SRAM**.

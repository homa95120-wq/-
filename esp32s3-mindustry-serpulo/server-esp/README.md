# `server-esp` — Авторитарный сервер ESP32-S3 (протокол `0x4D53`)

Компонент ESP-IDF, оборачивающий детерминированное ядро `simcore`:
- **Wi-Fi SoftAP:** `Mindustry-S3` / пароль `serpulo123`, IP `192.168.4.1`, TCP-порт `26789` (`TCP_NODELAY`).
- **USB / UART0:** автоматическое распознавание бинарных кадров `0x4D53` для подключения ПК-клиента по кабелю (`--serial COM7` или `/dev/ttyACM0`).
- **Буферизация:** `tx_buf` и потоковые парсеры размещаются в PSRAM (с fallback в обычную кучу), не расходуя стек задачи.
